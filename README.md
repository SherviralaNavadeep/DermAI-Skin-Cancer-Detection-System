
# DermAI – Skin Cancer Detection System

## About the Project
DermAI is an AI-based skin cancer detection system
that uses deep learning to classify skin lesion
images into benign or potentially malignant categories.

## Objective
To develop a system that helps users understand
skin lesion images using AI-based classification.

## Technologies Used
- Python
- JavaScript
- React
- TensorFlow
- Scikit-learn
- PostgreSQL

## Project Status
Frontend Development – Completed
Backend and Model Integration – In Progress

## Disclaimer
This project is for educational and research purposes.
It is not a substitute for professional medical diagnosis.
